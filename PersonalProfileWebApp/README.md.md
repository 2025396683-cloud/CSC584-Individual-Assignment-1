# **Personal Profile Web Application**



###### **1. Project Description**

Personal Profile Web Application is a simple web application was created for Individual Assignment 1 of CSC584. It lets users fill in their data using an HTML form, and then returns the data to the user in a JSP page.

The application is implemented with the use of Java Servlet to receive and process the submitted information using HTTP POST.



###### **2. Technologies Used**

Create the personal profile form with HTML.

\- Java Servlet: Processes the user information received from the web server through HTTP POST.

\- JSP (JavaServer Pages): Displays the submitted personal information.

\- CSS: Enables styling and enhances the application's looks.

\- GlassFish Server: To deploy and execute the web application.



###### **3. Software Requirements**

\- NetBeans IDE 8.2

\- JDK 8

\- GlassFish Server 4.1.1

\- Web Browser



###### **4. Application Features**

\- Input form for personal information.

\- Collects Name, Student ID, Programme, Email, Hobbies and Short Self-Introduction.

\- Submits information using HTTP POST.

\- Implements information using java servlets.

\- Reads profile information from JSP.

\- CSS Styled Beige Interface.



###### **5. To run the application, follow these steps:**

1\. Open NetBeans IDE 8.2.

2\. Open up the PersonalProfileWebApp project.

3\. Ensure that GlassFish server is configured and started.

4\. Right-click the project, and click on Clean and Build.

5\. When you see the words BUILD SUCCESSFUL you see the message, wait.

6\. Right click on the project and click Run.

7\. Go to your Web browser, and open the application.

8\. Fill in the personal information form.

9\. Click Submit Profile to see the information you submitted.



###### **6. Application Flow**

Convert HTML Form to Java Servlet (HTTP POST) to JSP Page.
